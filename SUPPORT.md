# Support

## PingAuthorize versions

| PingAuthorize | Bundle | Tested |
| ------------- | ------ | ------ |
| 11.1 | `*-paz11.zip` (`jakarta.servlet`) | Installed and run in a licensed server, with SPIRE, on every change |
| 10.2 | `*-paz10.zip` (`javax.servlet`) | Installed and run in a licensed server, with SPIRE, on every change |

Other 10.x and 11.x releases take the bundle for their major version and are expected to work.
Talk to us before relying on one we haven't tested.
